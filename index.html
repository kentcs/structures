Structure of Programming Languages

This course studies how programming languages are specified and implemented. We build Vertex in small steps, connecting syntax, parsing, evaluation, and runtime behavior.

Chapters

Chapter 0: What Is a Programming Language?
Language, syntax, semantics, and the implementation of Vertex.
 Chapter 1: Simple Expressions
Vertex's tokenizer, expression trees, recursive-descent parser, and evaluator.
 Chapter 2: Programs and Assignments
Programs, statements, assignment, print, and the environment model.
 Chapter 3: Strings and Basic I/O
String values, input and output, explicit conversions, and repeatable tests.
 Chapter 4: Booleans and Comparisons
Boolean values, comparisons, explicit conversions, and type inspection.
 Chapter 5: Logical Operators
Boolean operators, precedence, and short-circuit evaluation.
