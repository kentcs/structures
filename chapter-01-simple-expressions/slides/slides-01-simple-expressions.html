Vertex’s Expression Grammar

expression = term { ("+" | "-") term }
term = unary { ("*" | "/") unary }
unary = "-" unary | factor
factor = <number> | "(" expression ")"

Extended Backus-Naur Form (EBNF)

Braces repeat. A vertical bar separates alternatives.

Building a Term

left, tokens = parse_unary(tokens)
while tokens[0]["tag"] in ["*", "/"]:
    op = tokens[0]["tag"]
    right, tokens = parse_unary(tokens[1:])
    left = {"tag": op, "left": left, "right": right}
return left, tokens

3*-2 parses as multiplication with a negated right operand.

Unary Minus

if tokens[0]["tag"] == "-":
    operand, tokens = parse_unary(tokens[1:])

-5, 3*-2, and -(3+4) all use the same rule.

Requiring the Whole Expression

Evaluating the Tree

if ast["tag"] == "number":
    return ast["value"]
elif ast["tag"] == "+":
    return evaluate(ast["left"]) + evaluate(ast["right"])
elif ast["tag"] == "*":
    return evaluate(ast["left"]) * evaluate(ast["right"])
elif ast["tag"] == "unary-":
    return -evaluate(ast["operand"])

For 3+4*5: the children supply 3 and 20.
