An explicit update statement

    return x;

The rules for set

set x = expression;

Search the current environment, then its parents. Update the first existing binding of x. Raise an error if x does not exist.

Ordinary x = expression writes locally.

Nearest binding wins

x = 100;
function outer() {
    x = 10;
    function inner() { set x = x + 1 };
    inner();
    return x;
};
print(outer());
print(x);

set respects shadowing

x = 100;
function outer() {
    x = 10;
    function inner(x) {
        set x = x + 1;
        return x;
    };
    print(inner(3));
    return x;
};
print(outer());
print(x);

Prints 4, then 10, then 100

A counter with a captured binding

function makeCounter() {
    count = 0;
    return function() {
        set count = count + 1;
        return count;
    };
};
next = makeCounter();
print(next());
print(next());

Two methods, one private environment

function makeCounter() {
    count = 0;
    return {
        "increment": function() {
            set count = count + 1;
            return count;
        },
        "value": function() { return count }
    };
}

Independent instances

a = makeCounter();
b = makeCounter();
print(a.increment());
print(a.increment());

print(b.value());

An extracted method keeps its state

a = makeCounter();

The closure carries the connection to its instance.

Returning capabilities

readValue = a.value;
// Pass readValue to another function.
// It can observe this counter through that function.

An interface can expose selected operations. Returning the state itself exposes more access.

Binding update and object mutation

// Update an existing captured binding
set count = count + 1;

// Mutate data reached through a binding
state.count = state.count + 1;

// Assign in the current environment
count = count + 1;
