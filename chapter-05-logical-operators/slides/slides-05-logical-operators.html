Precedence Changes the Tree

not x == y      means   not (x == y)
a or b and c    means   a or (b and c)

The Expression Tree

Parser Levels

expression ::= logic_or
logic_or ::= logic_and { "or" logic_and }
logic_and ::= logic_not { "and" logic_not }
logic_not ::= "not" logic_not | comparison

Each level calls the next tighter level.

One Comparison at a Time

1 < 2 < 3             rejected
1 < 2 and 2 < 3       true
(1 < 2) == true       true

Parentheses settle grouping, not operand types.
